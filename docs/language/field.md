# Выражения (Field Resolver)

**Выражение** — всё, что стоит в позиции «значение» в конфиге:
в `extra`, `mapping`, `params`, `response`, `compose`.
Field Resolver превращает выражение в конкретное значение.

---

## Литералы и типы

Всё, что не распознано как специальная конструкция, возвращается как есть:

| Вход                 | Результат                             |
| -------------------- | ------------------------------------- |
| `'NEW'`              | строка `'NEW'`                        |
| `42`, `true`, `null` | то же значение того же типа           |
| `['a' => 1]`         | массив как есть                       |
| `'unknown:value'`    | строка как есть (неизвестный префикс) |

---

## `field:` — чтение из контекста

```php
'field:name'            // контекст['name']
'field:CONTACT.NAME'    // контекст['CONTACT']['NAME'] — точечная нотация
'field:A.B.C.D'         // любая глубина
```

Правила:

- поле не найдено → `null` (без исключения);
- ключи с точкой в имени не поддерживаются (точка = разделитель пути);
- работает во всех блоках и внутри шаблонов `{{ }}`.

---

## Цепочка альтернатив `|`

```php
'field:CONTACT_PHONE.VALUE|field:COMPANY_PHONE.VALUE|field:phone'
```

- возвращается **первое найденное** (не `null`) значение;
- все `null` → результат `null`;
- работает внутри `{{ }}`: `{{field:A|field:B}}`.

Типичный кейс — телефон контакта, иначе компании, иначе из запроса.

---

## Шаблоны `{{ }}`

Строка, содержащая `{{ выражение }}`, становится шаблоном:

```php
'Клиент {{field:NAME}}, тел: +{{field:phone}}'
// → 'Клиент Иван, тел: +79990000000'
```

### Семантика

| Случай                                  | Результат                                            |
| --------------------------------------- | ---------------------------------------------------- |
| Текст + плейсхолдеры                    | Строка с подстановкой                                |
| `null` в плейсхолдере внутри текста     | Пустая строка: `'+{{field:phone}}'` → `'+'`          |
| Одиночный `{{выражение}}` на всю строку | **Сырое значение с типом** (число останется числом)  |
| `+` снаружи скобок                      | Обычный литерал: `'+{{field:phone}}'` → `'+7999...'` |

### Шорткаты (голые пути)

Внутри `{{ }}` префикс `field:` можно не писать:

```php
'{{LEAD.LAST_NAME}} {{LEAD.NAME}} {{LEAD.SECOND_NAME}}'
// → 'Иванов Иван '   (null-отчество дало пустую строку)
```

Голый путь — идентификатор с точками: `LEAD.NAME`, `user_id`.

### Скобки-литералы

Если внутри `{{ }}` **нет** похожего на путь выражения — скобки остаются:

```php
'a {{ 100 }} c'   // → 'a {{ 100 }} c'  (100 — не путь)
'a {{ b }} c'     // → 'a  c'           (b — валидный шорткат, null → '')
```

## `func:` — функции для условий

```php
'func:empty'        // проверка «пусто»
'func:is_numeric'   // проверка «число»
```

В позиции значения возвращает служебную структуру
`['type' => 'function', ...]` — предназначена для **условий**
(см. [Условия](conditions.md)), а не для подстановки значений.

---

## `method:` — ссылка на метод класса

```php
'method:App\Service->isUnactive'   // instance-метод (static: false)
'method:App\Service::isUnactive'   // статический (static: true)
```

- возвращает дескриптор `{class, method, static}` — используется
  в условиях `execute` и `filter`;
- статичность определяется по разделителю (`->` / `::`);
- формат без класса (`method:someMethod`) → структура с `error`
  («Invalid method format»), а не исключение.

> Не путать с вызовом метода: вызов делается в `extra`/`query`
> через блок `['method' => ..., 'class' => ...]` (см. Method Resolver).

---

## `result` — результат последнего действия

```php
'result'        // весь результат последнего вызова метода
'result:ID'     // поле результата
```

`lastResult` обновляется после каждого вызова в `extra`/`query`/`execute`.

## Сводная таблица

| Конструкция           | Пример               | Результат                      |
| --------------------- | -------------------- | ------------------------------ |
| Литерал               | `'NEW'`              | `'NEW'`                        |
| Поле                  | `'field:A.B'`        | значение или `null`            |
| Цепочка               | `'field:A\|field:B'` | первое не-null                 |
| Шаблон                | `'{{A}} {{B}}'`      | строка, null → `''`            |
| Одиночный плейсхолдер | `'{{count}}'`        | сырое значение (5, а не `'5'`) |
| Шорткат               | `'{{LEAD.NAME}}'`    | как `{{field:LEAD.NAME}}`      |
| Функция               | `'func:empty'`       | структура для условий          |
| Метод                 | `'method:C->m'`      | дескриптор для условий         |
| Результат             | `'result:ID'`        | поле последнего результата     |

---

## Где какие конструкции работают

| Позиция в конфиге                                     | Допустимые конструкции                                                          |
| ----------------------------------------------------- | ------------------------------------------------------------------------------- |
| Значения `extra` / `mapping` / `compose` / `response` | литералы, `field:`, цепочки, `{{ }}`, `result:`                                 |
| `params` методов                                      | всё вышеперечисленное + `'mapping'` + вложенные массивы (резолвятся рекурсивно) |
| `filter` / `conditions`                               | равенства, `!field:`, `func:*`, `method:*` — см. [Условия](conditions.md)       |
